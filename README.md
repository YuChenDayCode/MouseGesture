# Mouse Gesture

一个常驻托盘的 Windows 全局右键手势小工具：按住鼠标右键上下滑动，快速跳到页面顶部或底部。

## 手势

| 操作 | 效果 |
| --- | --- |
| 按住右键向上滑 | 发送 `Ctrl+Home`（跳到顶部） |
| 按住右键向下滑 | 发送 `Ctrl+End`（跳到底部） |
| 右键单击（位移不足阈值） | 正常弹出右键菜单 |
| 按住右键左右滑 | 不触发任何操作 |

默认位移阈值为 64 像素，且必须以竖直方向为主才会触发。

## 使用

- 运行后程序驻留在系统托盘，同一时间只允许运行一个实例。
- 托盘右键菜单可以勾选或取消“启用手势”，双击托盘图标也可以快速切换。
- 从托盘菜单选择“退出”即可关闭并卸载鼠标钩子。

## 构建

需要 Windows 和 .NET 8 SDK。

```bash
# 调试运行
dotnet run

# 以 Native AOT 发布 win-x64 版本
dotnet publish -p:PublishProfile=win-x64-aot
```

发布产物位于 `bin\Release\net8.0-windows\win-x64\publish\`。

## 实现简介

- 通过 `SetWindowsHookEx(WH_MOUSE_LL)` 安装全局低级鼠标钩子，先吞掉右键按下，松开时再判断是单击还是手势。
- 普通单击会通过 `SendInput` 回放右键；回放和手势按键都带有自定义 `dwExtraInfo` 标记，钩子见到就放行，避免被重复拦截。
- 手势按键通过 `SynchronizationContext` 投递到 UI 线程发送，不在钩子回调里直接调用 `SendInput`。

## 已知限制

- 程序以普通权限运行，Windows 的权限隔离会阻止它向以管理员身份运行的窗口回放输入，因此在这类窗口中右键可能失效。
- 横向拖动右键既不触发手势，也不会回放右键，依赖右键拖拽的操作（如资源管理器中右键拖动文件）会受影响。
